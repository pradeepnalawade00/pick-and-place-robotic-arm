# Pick and Place Robotic Arm 🤖

This project is an IoT-based robotic arm capable of picking and placing objects.

## Features
- Controlled via mobile app
- Uses Arduino and servo motors
- Wireless communication (Bluetooth/WiFi)

## Components
- Arduino Uno
- SG90 Servo Motor
- MG996R Servo
- HC-05 Bluetooth Module
